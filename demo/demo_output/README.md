# Pre-computed Benchmark Results 📊

This folder contains pre-computed outputs generated by `sclongcallr pipeline` on the demo single-cell cancer dataset.

### Output Files
1. **`candidate_snps.json`**:
   - High-confidence single-cell candidate SNPs called via cluster-aware pseudo-bulk pooling and the ResNet variant caller.
   - Includes zygosity classification (`0/1`), diploid genotypes (`C/T`, `G/A`), Phred quality metrics, and A-to-I editing discrimination.

2. **`cancer_loh_events.json`**:
   - Statistically confirmed Loss of Heterozygosity (LOH) events identified by the cancer aneuploidy likelihood engine.
   - Shows *TP53* region LOH in `Malignant_Subclone_A` ($H_1 = 18, H_2 = 1, AI = 0.8947, p = 7.6 \times 10^{-5}$) while proving infiltrating immune T-cells are diploid.

3. **`sclongcallr_phased_obs.csv`**:
   - Cell-level metadata table containing total phased reads, $H_1$ counts, and $H_2$ counts for each single cell.

4. **`sclongcallr_phased_var.csv`**:
   - Genomic block feature table containing chromosome coordinates and SNP counts per phase block.

5. **`sclongcallr_phased.npz`**:
   - Compressed sparse haplotype matrices (`hap1_counts`, `hap2_counts`, `allele_ratio`) ready to be converted into AnnData (`.h5ad`) for Scanpy / Seurat visualization.
